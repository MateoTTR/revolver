## Work Completed

### Sprint 006c — LLM Config & Iteration Tracking

**PR #73** — `feature/s6c-llm-config-iteration-tracking`

Feature 1 — LLM per-model config:
- Added `max_tokens` and `timeout_s` optional fields to `LLMEntry` model
- DB migration v3→v4 (3 new columns: `max_tokens`, `timeout_s`, `valid_iterations`)
- Updated `register_llm()` with positive-value validation
- Added `--max-tokens` and `--timeout` CLI options to `llm add`
- `build_config()` injects values at step 2b (after problem config, before `--config-override`)
- `llm list` conditionally shows config columns when set

Feature 2 — Iteration success rate:
- `count_valid_programs()` reads OpenEvolve `database.json` from checkpoint
- Wired into both `launch_run()` and `resume_run()`
- `run info` shows `Iterations: X/Y valid (Z%)`
- `run list` shows success rate column

Code review findings fixed:
- W1: Positive-value validation on `max_tokens` and `timeout_s`
- W2: `json` import moved to module level
- S3: `count_valid_programs()` returns `None` on unknown dict format
- S4: Rebased on develop to eliminate diff noise
