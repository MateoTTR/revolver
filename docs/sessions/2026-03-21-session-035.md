### F1 Fix: --json Option Propagation (PR #81)

- **Root cause**: `--json` was defined on the root Typer callback only. Click groups parse their own options before delegating to subcommands, so `revolver llm list --json` failed with "No such option" while `revolver --json llm list` worked.
- **Fix**: Created `GlobalOptionGroup` and `GlobalOptionCommand` custom Click subclasses in `src/revolver/cli/_global_options.py` that intercept `--json`, `--verbose`, `--quiet` at parse time before Click's normal processing.
- **Scope**: Applied to root app + all 8 sub-Typer groups via `cls=GlobalOptionGroup` in `__init__.py`.
- **Tests**: 2 new integration tests covering `--json` after subcommand and on group level.
- **Result**: 801 tests pass, all 3 flag positions work (`revolver --json llm list`, `revolver llm --json list`, `revolver llm list --json`).
