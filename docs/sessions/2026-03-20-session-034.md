## Architecture Decisions

- `doctor` and `setup` registered as **top-level commands** on `app` (not subgroups) — they are global commands that work without a project
- Ollama status depends on conda availability: FAIL (fixable) when conda is available, WARN (manual) when not — per spec-setup.md §4
- `print_confirmation()` centralized in `infra/output.py` — respects both `--json` and `--quiet` modes
