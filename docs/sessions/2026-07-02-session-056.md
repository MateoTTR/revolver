## Incidents / learnings

- **CI push+ready race**: running `git push` and `gh pr ready` in a single command fires two `pull_request` events within the same second; the workflow's `concurrency: cancel-in-progress` cancels one and skips the other → a MERGEABLE PR with **no green run**. Recovered by `gh pr close` + `gh pr reopen` (a `reopened` event on the now-non-draft PR; an empty commit won't work — `paths-ignore` may skip it). Space the two steps. (Saved to memory.)
- **`git add -A` swept a stray `--json` SQLite file** (created by a pre-fix CLI test) into a W3 commit — caught before merge, removed via amend + force-push.
- **Stray commit on `main`**: after the release merge I stayed on `main` and a backlog bookkeeping commit landed there (never pushed). Relocated to `develop` via cherry-pick; reset local `main` to `origin/main` (the tagged state). No remote impact.
