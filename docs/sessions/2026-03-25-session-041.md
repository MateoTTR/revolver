- **Review cascade order**: spec-reviewer → validation-reviewer → doc-reviewer (source of truth first, then traceability, then user-facing docs)

- **Token strategy**: `GITHUB_TOKEN` from `gh auth token` in shell profile (option B) — no secrets in committed files
