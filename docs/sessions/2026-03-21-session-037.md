### Process Improvements

1. **Code-reviewer agent fix**: Added `Write` tool to agent frontmatter — agents were silently failing to post review comments because they couldn't create temp files for `gh pr comment --body-file`.

2. **CI matrix reduction**: Removed Python 3.13 from CI (keep 3.12 + 3.14). The 3.13 runner was consistently slow/stuck, and 3.12+3.14 provide sufficient coverage.

3. **GitHub default branch**: Changed from `main` to `develop` so that `Closes #N` in PR descriptions auto-closes issues when merging to `develop` (our PR target).

4. **Stale issue cleanup**: Batch-closed 21 old issues from Sprints 001-007a that were left open due to the default branch mismatch.

5. **MCP GitHub server**: Configured user-level MCP server in `~/.claude/.mcp.json` using `gh auth token` for dynamic authentication. Available for future sessions.

### Code Review Findings (addressed)

- **PR-A**: Fixed `evaluator_dualmode.py` fixture — `evaluate_instance` arity (1 arg instead of 2), fixed docstring in `evaluator_neither.py`
- **PR-C** (critical): Fixed config key mismatch — `launch_run()` read from `oe_config["evaluator"]` but user config template uses `evaluation:`. Fixed to check both keys with fallback.
