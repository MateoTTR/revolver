## Pre-sprint discussion

Before starting implementation, discussed current limitations of program management:
- OpenEvolve handles programs as raw text — language-agnostic for the evolved program
- The evaluator (always Python) can compile/execute any language via subprocess
- Revolver forces `initial_program.py` name — only cosmetic constraint for non-Python
- Pre-installed packages (numpy, ortools) work for both program and evaluator
- Local file dependencies break for the program (OE writes to temp files) but work for the evaluator
- Added 4 v2 backlog items (#132-135): multi-language, program support files, dependency traceability, multi-language docs
