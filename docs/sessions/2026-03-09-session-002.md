## Key Decisions Made (Session 002)

| Decision | Choice | Rationale |
|---|---|---|
| Dataset storage | Hash-only by reference (no copy), `--snapshot` option for full copy | Avoid duplicating large datasets |
| Evaluator dual-mode | Must support single-instance + aggregated mode | Required for both Revolver eval and OpenEvolve training |
| Multi-objective metrics | All dict values are `float`, stats computed per key | OpenEvolve constraint, natural for multi-objective |
| Objective direction | V1 agnostic — raw stats only, user interprets | Simple, avoids imposing conventions |
| Language agnosticism | Revolver stores source only; evaluator handles compile/run | Consistent with OpenEvolve architecture |
| POC Local LLM | Dedicated POC in `/home/mathi/revolver-pocs/local-llm/` | Validate WSL2 + CUDA + GPU before architecture decisions |
