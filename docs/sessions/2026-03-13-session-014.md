### Task 34: Token/Cost Tracking Design

Lightweight integration of token usage and cost estimation across the documentation:

**Design decisions**:
- **DD-14** (DES-005): Transparent HTTP proxy between OpenEvolve and LLM API intercepts `usage` fields from OpenAI-compatible responses
- Optional LLM pricing (`--input-cost`, `--output-cost` in USD per Mtok) stored in DB, cost computed at read time
- `prompt_tokens` and `completion_tokens` stored in `runs` table (NULLable)
- `estimated_cost_usd` computed at read time, never persisted
- Config snapshot caveat: will contain proxy URL, not real LLM endpoint (documented)
