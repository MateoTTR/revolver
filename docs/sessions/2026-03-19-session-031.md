## Key decisions

- **eval_id collision strategy**: Chose counter-based retry loop (same as benchmark_id) over solution-prefix approach. Simpler, proven pattern, no fragile ID parsing.
- **Default metric**: Hardcoded `combined_score` as default display metric. Fallback to first metric if absent. `--metric all` for power users.
- **--all scope**: Resolves aliases when available, falls back to solution ID. No filtering by status.
