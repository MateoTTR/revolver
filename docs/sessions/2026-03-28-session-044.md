## Traceability Analysis

Deep analysis of run lineage revealed gaps:
- `llm_model` column can only store one model → ensemble info lost
- `llm update --model` after run: temperature/max_tokens not structuredly snapshotted
- Delete+re-create LLM with same name: `llm_model` snapshot protects but querying by name gives heterogeneous results

**Solution implemented**: `llm_snapshot TEXT` JSON column on `runs` table (Level 2 — structured snapshot)
