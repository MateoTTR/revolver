### Bug B1 Investigation — Post-"Evolution completed" Hang

- **Root cause identified**: `ProcessPoolExecutor.shutdown(wait=True)` in OE's `ProcessParallelController.stop()` blocks indefinitely when workers are mid-execution (SDK retry loop, toxic program)
- **Reproduced** with minimal script (`repro-b1-hang.py`): deterministic hang on `shutdown(wait=True)` when workers are in retry loops
- **Evidence from logs**: Gemini Flash run shows workers continuing 429 retries after shutdown signal
- **Decision**: upstream issue, not Revolver workaround — any watchdog has poor UX tradeoffs
- **Filed comment on [openevolve#297](https://github.com/algorithmicsuperintelligence/openevolve/issues/297#issuecomment-4103946135)** with repro script, production logs, and proposed fix
