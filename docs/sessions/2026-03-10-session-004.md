## Spec Review — Changes Applied

### New: Deployment & Dependencies (NFR-060 to NFR-068)
- Revolver installable via pip, Python dependencies auto-declared
- Non-Python deps (Ollama, nvidia-smi) detected at runtime, never installed by Revolver
- New commands: `revolver doctor` (health check) and `revolver setup` (assisted install)
- New spec file: `spec-setup.md` (13 FRs: FR-SET-001 to FR-SET-013)

### Eval & Benchmark: Raw Per-Instance Storage
- SQLite stores full `dict[str, float]` per instance (not just aggregates)
- Aggregates computed at read time — enables future post-processing (histograms, plots)
- `--per-instance` flag on eval results, benchmark results, and benchmark export
- Benchmark per-instance comparison identifies best solution per instance
- New FRs: FR-EVL-017, FR-BEN-014 to FR-BEN-016

### Split Train/Eval: Warning Instead of Blocking
- `run`, `eval`, `benchmark` warn (not block) when dataset split doesn't match expected usage
- Training results stored by `run` (FR-RUN-019, FR-RUN-020) and accessible via `eval results`

### Project Simplifications
- Removed `--domain` option from `project init`
- Explicit constraint: one problem per project (multiple versions OK)
- Run is foreground-only for V1

### User Story
- Created `docs/specs/user-story-e2e.md` — end-to-end workflow from project init to benchmark export
- Scenario: Alice optimizes job-shop scheduling with local + remote LLMs

## Architecture Decisions

### ADR-001 — Ollama as Local LLM Backend (Accepted)
- Formalized POC decision: Ollama selected over vLLM
- Key factors: 9x throughput, 4x less VRAM, simple lifecycle, native OpenAI-compat API
- Risks documented: Q4 quality, model updates, 72B impractical

### ADR-002 — Python as Implementation Language (Accepted)
- Python >= 3.11
- Key factors: native OpenEvolve integration, same language as evaluators, ML ecosystem, pip-installable
- Startup ~200ms acceptable (NFR-030 < 2s)
