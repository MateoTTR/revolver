## Decisions Made

| Decision | Rationale |
|---|---|
| A+B hybrid strategy (ADR-006) | Strategy A is simple and cross-platform; Strategy B adds optional per-instance visibility; Strategy C is fragile |
| Use `OpenEvolve` controller class, not `run_evolution()` | Only the controller class supports checkpoint resume |
| Revolver generates the wrapper evaluator | User writes only `evaluate_instance()`, reducing boilerplate and ensuring correct dual-mode pattern |
