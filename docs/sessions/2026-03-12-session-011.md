### DES-007 — Benchmark Design (v0.1)

New document: `docs/architecture/design/DES-007-benchmark-design.md`

Key design decisions:
- **DD-01**: No stored aggregates — compute at read time from raw `eval_instances` (consistent with DES-006 DD-01)
- **DD-02**: Benchmark stores references only (`benchmark_solutions`), not data — single source of truth in eval tables
- **DD-03**: CSV + JSON only, no Parquet in v1 (resolves AQ-05) — Parquet adds ~150MB dependency for marginal benefit; `--per-instance` export provides raw data for external tools
- **DD-04**: Benchmark triggers eval with `force=True` — no double confirmation, suppresses DES-006 D-006-a prompt
- **DD-05**: Sort by configurable metric, default `combined_score` mean
- **DD-06**: User aggregates displayed alongside Revolver aggregates (consistent with DES-006 DD-07)
- **DD-07**: Failed solutions included as warning, not persisted in `benchmark_solutions`
