### Research: OpenEvolve + Gemini thinking mode

Investigated why Gemini Flash/Pro produce 0% valid diffs while Flash-Lite works fine:
- **Root cause**: thinking tokens consume `max_tokens` budget silently (not visible in response)
- Flash-Lite: thinking disabled by default → full budget for code output
- Flash/Pro: thinking enabled → budget exhausted on internal reasoning → empty response
- OpenEvolve's diff parser would tolerate preamble text (regex with `re.DOTALL`)
- Solutions: disable thinking (`reasoning_effort: "none"`), increase `max_tokens`, or use Flash-Lite
- Updated backlog: #120 requalified (auto-config thinking), #121 deprioritized (proxy filtering not needed)

### Permission patterns analysis

Analyzed Claude Code permission matching for `settings.local.json`:
- Chained commands (`&&`, `;`) are decomposed and checked individually
- `cd` generates Read rules, subsequent commands matched against Bash rules
- `Bash(*)` allows all commands (viable for isolated worktree agents)
- Recommendation: add `Bash(cd *)` or consider `Bash(*)` given worktree isolation + code review
