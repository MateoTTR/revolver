# Sprint records

The sprint files in this directory (`sprint-001.md` … `sprint-019.md`) are
**historical planning records**. They are frozen at the end of Sprint 019
(v0.19.0) and are no longer updated; nothing here is moved or renumbered.

From Sprint 020 on, planning is GitHub-native:

- a **sprint** is a GitHub **milestone** plus a **planning issue** that carries
  the scope, the task breakdown and the parallelization notes;
- the **backlog** is the GitHub issue list (labels replace the numbered rows of
  [`docs/tasks/backlog.md`](../tasks/backlog.md), itself frozen);
- the **sprint review** becomes the release entry in
  [`CHANGELOG.md`](../../CHANGELOG.md), plus the closing comment of the
  planning issue.

"Session NNN" references inside the sprint files point to the maintainer's
private journal, which is kept outside the repository (see
[`docs/sessions/README.md`](../sessions/README.md)).
